# Pixel video reference frames

Single-character 9:16 (720x1280) stills of Pixel (she/her) made to drive talking-avatar video models
(InfiniteTalk, Wan2.2 S2V). Each shows one pose on a plain background with her face visible and her mouth
closed or neutral, which keeps the first frame clean for lip sync.

Made with an image-edit model from `reference/pixel-turnaround-original.jpg`.

| File | Pose |
|---|---|
| `pixel-front-sitting.jpg` | Front, sitting (main ref) |
| `pixel-three-quarter.jpg` | 3/4 view |
| `pixel-waving.jpg` | Waving |
| `pixel-coffee-mug.jpg` | Holding a coffee mug |
| `pixel-laptop.jpg` | At a laptop |
